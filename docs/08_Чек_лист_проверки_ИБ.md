## J. Smoke-check (ручная проверка)

Выполнить после развёртывания:

```bash
# 1. Редирект HTTP → HTTPS
curl -sI http://<SERVER_NAME>/ | findstr "301"

# 2. Без auth → 401
curl -sk https://<SERVER_NAME>/dashboard -o NUL -w "%{http_code}"

# 3. С auth → 200
curl -sk -u user:pass https://<SERVER_NAME>/dashboard -o NUL -w "%{http_code}"

# 4. /ready с рабочей станции → 403
curl -sk https://<SERVER_NAME>/ready -o NUL -w "%{http_code}"

# 5. Backend порт закрыт
# Test-NetConnection <host> -Port 8000  → должно fail

# 6. Автоматическая проверка
python scripts/security_check.py
```
