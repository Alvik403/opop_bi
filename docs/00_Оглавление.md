# Документация проекта «Дашборд ОПиОП BI»

## Краткие технические характеристики

| Параметр | Значение |
|----------|----------|
| Тип системы | Внутренний BI-дашборд (web) |
| Backend | FastAPI, Python 3.12, uvicorn |
| Frontend | Jinja2 + Vite + Tailwind + Chart.js + Univer |
| БД | SQLite (метаданные файлов) |
| Данные | Excel `.xlsx` (лист калькуляции), без ПДн |
| Аутентификация | HTTP Basic Auth (временно до SSO) + CSRF |
| Публикация | HTTPS `:443` через `opop_bi_nginx`; порт `8000` не на хосте |
| Контейнеры | `opop_bi_nginx` (UID 101), `opop_bi_web` (UID 10001) |
| ОС / Docker (реком.) | Ubuntu 22.04/24.04 LTS, Docker Engine 29.x + Compose v2 |
